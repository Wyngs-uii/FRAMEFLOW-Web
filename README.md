# FRAMEFLOW · 在线创作工作台

访问网站：**https://wyngs-uii.github.io/FRAMEFLOW-Web/**

公开前端演示版。先阅读两份完整人工剧本示例，或填写空白模板。演示版需要自己补全剧情和台词；可以编辑分镜计划、检查顺序和时长，导入或导出项目 JSON。

项目自动保存在当前浏览器；更换设备或清理浏览器前，请导出项目 JSON 备份。示例主题用于练习，不代表实时热榜。

此版本未启用 AI 编剧、实时采集、视频生成或 MP4 渲染。没有服务端、API Key 或数据库。完整开发源码保留在独立私有仓库。

本机完整版本：先双击电脑项目目录的 `启动_FRAMEFLOW.command`，再打开 http://127.0.0.1:8765。支持实际热榜和公开网页采集，以及带情节、台词和分镜计划的 AI 扩写。无需妙搭或飞书登录。

通过 GitHub Actions 自动发布到 GitHub Pages。
